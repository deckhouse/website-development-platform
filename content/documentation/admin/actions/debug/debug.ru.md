Debug выполняет отладочное действие. Позволяет сделать заданное число циклов ожидания, а также записать произвольные данные в лог и вернуть их в ответе действия.

### Пример запроса

```yaml
sleep_time: 1
sleep_count: 3
extra:
  example_key: example_value
```

### Спецификация запроса

| Название     | Обязательность | Описание                                                                                             | Значение по умолчанию |
|---------------|----------------|-----------------------------------------------------------------------------------------------------|-----------------------|
| sleep_time    | Нет            | Длительность одного цикла ожидания в секундах                                                       | `1`                   |
| sleep_count   | Нет            | Число циклов ожидания                                                                               | `1`                   |
| extra         | Нет            | Произвольный набор пар «ключ–значение», который записывается в лог и возвращается в ответе действия | -                     |
