{{< alert level="info" >}}
Для выполнения действий требуется токен SonarQube с типом User Token, сгенерированный пользователем, от имени которого выполняется действие.
{{< /alert >}}

DeleteSonarqubeProject — удаляет проект из SonarQube.

## Пример запроса

Пример тела запроса действия:

```yaml
project: example-project
```

## Спецификация запроса

Тело запроса действия поддерживает следующие параметры:

| Название           | Обязательность   | Описание                                                                     | Значение по умолчанию    |
| ------------------ | ---------------- | ---------------------------------------------------------------------------- | ------------------------ |
| `project`          | Да               | Уникальный идентификатор (Project Key) проекта, который необходимо удалить   | —                        |
