{{< alert level="info" >}}
Running this action requires a SonarQube User Token generated by the user on whose behalf the action will run.
{{< /alert >}}

DeleteSonarqubeProject — deletes a project from SonarQube.

## Request example

Example of the action request body:

```yaml
project: example-project
```

## Request specification

The action request body supports the following parameters:

| Name               | Required | Description                                                                   | Default value              |
| ------------------ | -------- | -------------------------------------------------------------------------------- | ------------------------ |
| `project`          | Yes      | Unique identifier (Project Key) of the project to delete                          | —                        |
