{{< alert level="info" >}}
Для выполнения действия необходимо наличие токена — строки base64(`admin:password`), используемой как Basic Auth при запросах к Nexus.
{{< /alert >}}

DeleteNexusUser — удаляет пользователя из Nexus Repository Manager 3.

### Пример запроса

```yaml
userId: example-user
```

### Спецификация запроса

| Поле     | Обязательность    | Описание                                               |
| -------- | ----------------- | ------------------------------------------------------ |
| userId   | Да                | Идентификатор пользователя, которого требуется удалить |
