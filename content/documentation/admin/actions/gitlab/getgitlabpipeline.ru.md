GetGitlabPipeline — возвращает состояние пайплайна GitLab.

Действие применяется в процессах, которые запускают пайплайн действием [StartGitlabPipeline](../startgitlabpipeline/) и затем ожидают его завершения, периодически опрашивая состояние.

### Пример запроса

```yaml
project_id: "0"
pipeline_id: "0"
```

### Спецификация запроса

| Название    | Обязательность | Описание                              |
| ----------- | -------------- | ------------------------------------- |
| project_id  | Да             | Идентификатор проекта GitLab          |
| pipeline_id | Да             | Идентификатор пайплайна               |

### Примечание

Действие осуществляет GET-запрос по URL: `/api/v4/projects/:id/pipelines/:pipeline_id`. Ответ пайплайна попадает в результат действия и доступен последующим элементам процесса.
