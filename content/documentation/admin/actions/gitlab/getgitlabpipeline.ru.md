GetGitlabPipeline — возвращает состояние пайплайна GitLab.

Действие используется в процессах, которые запускают пайплайн действием [StartGitlabPipeline](startgitlabpipeline/) и ожидают его завершения, периодически запрашивая состояние.

### Пример запроса

```yaml
project_id: "0"
pipeline_id: "0"
```

### Спецификация запроса

| Название    | Обязательность | Описание                                                                                          |
| ----------- | -------------- | ------------------------------------------------------------------------------------------------- |
| project_id  | Да             | Идентификатор проекта GitLab или путь проекта, например `group/project`                            |
| pipeline_id | Да             | Идентификатор пайплайна — поле `id` ответа GitLab, например `{{ .response.id }}` действия StartGitlabPipeline |

### Ответ

Ответ действия — объект пайплайна GitLab с полями `id`, `iid`, `status`, `ref`, `sha`, `web_url` и другими. Состояние пайплайна доступно в последующих элементах процесса как `{{ .response.status }}`.

### Примечание

Действие осуществляет GET-запрос по URL: `/api/v4/projects/:id/pipelines/:pipeline_id`.
