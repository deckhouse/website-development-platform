{{< alert level="info" >}}
Для выполнения действия требуется токен пользователя, от имени которого оно будет выполнено.
{{< /alert >}}

CreateRepositoryFromTemplatePack — наполняет репозиторий содержимым [пакета шаблонов](../../../templates/) из реестра.

Действие скачивает указанную версию шаблона, подставляет в файлы значения и коммитит результат в целевой репозиторий. Дополнительно оно записывает файл `.ddp/template.lock.yaml` с идентификатором и версией шаблона — по нему платформа позже определяет, что сервис можно обновить.

### Пример запроса

```yaml
targetRepositoryUrl: https://gitlab.example.com/group/service.git
targetBranch: main
templateId: go-service
templateVersion: 1.2.0
commitMessage: Create repository from template
values:
  serviceName: billing-api
```

### Спецификация запроса

| Название                 | Обязательность | Описание                                                                          |
| ------------------------ | -------------- | ----------------------------------------------------------------------------------- |
| targetRepositoryUrl      | Да             | HTTPS-адрес репозитория, в который записывается результат                          |
| targetBranch             | Нет            | Ветка для коммита; по умолчанию — ветка из настроек реестра шаблонов               |
| templateId               | Да             | Идентификатор шаблона в реестре                                                    |
| templateVersion          | Да             | Версия шаблона                                                                     |
| templatePackSource       | Нет            | Название реестра, если один шаблон публикуется в нескольких                        |
| values                   | Нет            | Значения шаблона; набор полей описан в самом пакете                                |
| additionalIgnorePatterns | Нет            | Дополнительные пути, исключаемые из шаблонизации                                   |
| commitMessage            | Нет            | Сообщение коммита                                                                  |

### Примечание

Хост `targetRepositoryUrl` проверяется по адресу внешнего сервиса, указанного в действии: это не даёт отправить учётные данные в посторонний репозиторий.
