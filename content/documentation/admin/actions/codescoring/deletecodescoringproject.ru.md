DeleteCodeScoringProject — удаляет проект в системе CodeScoring по его ID.

### Пример запроса

```yaml
id: 1
```

### Спецификация запроса

| Название   | Обязательность   | Описание                      |
| ---------- | ---------------- | ----------------------------- |
| id         | Да               | ID проекта в CodeScoring      |
