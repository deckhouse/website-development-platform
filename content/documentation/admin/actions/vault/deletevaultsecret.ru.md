{{< alert level="info" >}}
Для выполнения действия необходим Vault-токен с правами на чтение и удаление секрета по указанному пути.
Для пути KV v2 (содержит `/data/`) токену также необходимы права на удаление соответствующего пути `/metadata/`.
{{< /alert >}}

DeleteVaultSecret — удаляет секрет из HashiCorp Vault.

### Пример запроса

```yaml
path: example/data/path
```

### Спецификация запроса

| Название                    | Обязательность   | Описание                                                                                             |
| --------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------- |
| path                        | Да               | Путь, по которому находится секрет в Vault, который необходимо удалить                               |
