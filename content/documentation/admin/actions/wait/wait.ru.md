Wait ожидает заданное число секунд; дополнительно может применяться случайная добавка к длительности (джиттер). Предназначено для использования в процессах в качестве элемента задержки, в том числе для ожидания применения результатов предыдущего действия.

### Пример запроса

```yaml
duration_seconds: 10
max_jitter_seconds: 0
description: "Waiting for release"
```

### Спецификация запроса

| Название              | Обязательность   | Описание                                                                           | Значение по умолчанию  |
| --------------------- | ---------------- | ---------------------------------------------------------------------------------- | ---------------------- |
| duration_seconds      | Нет              | Базовая длительность ожидания в секундах, от `0` до `86400` (24 часа)              | `0`                    |
| max_jitter_seconds    | Нет              | Максимальная случайная добавка к ожиданию в секундах (0–N). 0 — джиттер отключён   | `0`                    |
| description           | Нет              | Описание для отображения в логах и ответе действия                                 | -                      |

Общая длительность ожидания с учётом джиттера не превышает 86400 секунд.

### Ответ

Действие возвращает следующие поля:

| Название                 | Описание                                                      |
| ------------------------ | ------------------------------------------------------------- |
| `duration_seconds`       | Базовая длительность ожидания из запроса в секундах           |
| `applied_jitter_seconds` | Случайная добавка, применённая в этом запуске, в секундах     |
| `total_seconds`          | Фактическая длительность ожидания в секундах                  |
| `description`            | Описание из запроса                                           |

Например, `{{ .response.total_seconds }}` возвращает фактическую длительность ожидания.
