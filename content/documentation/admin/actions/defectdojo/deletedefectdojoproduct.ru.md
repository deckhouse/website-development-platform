Для выполнения действия требуется токен API v2 Key пользователя, от имени которого выполняется действие.

DeleteDefectdojoProduct — удаляет продукт из DefectDojo. Действие использует DefectDojo API v2.

## Пример запроса

Пример тела запроса действия:

```yaml
id: 1
```

## Спецификация запроса

Тело запроса действия поддерживает следующие параметры:

| Название      | Обязательность   | Описание                                             | Значение по умолчанию    |
| ------------- | ---------------- | ---------------------------------------------------- | ------------------------ |
| `id`          | Да               | Идентификатор продукта, который необходимо удалить   | —                        |
