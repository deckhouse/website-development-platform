DeleteDefectdojoProduct — deletes a product from DefectDojo. The action uses the DefectDojo API v2.

### Request example

```yaml
id: 1
```

### Request specification

| Name          | Required | Description                                   | Default value             |
| ------------- | -------- | ------------------------------------------------ | ------------------------ |
| id            | Yes      | Identifier of the product to delete               | -                        |
