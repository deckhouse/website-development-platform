Раздел описывает устройство Deckhouse Development Portal (DDP, портал): его назначение, компоненты, сетевые взаимодействия и фоновую обработку задач.
Сведения помогут спланировать установку, настроить сетевой доступ и диагностировать работу портала.

Раздел состоит из следующих страниц:

| Страница | Содержание |
| --- | --- |
| [Верхнеуровневая архитектура](high-level-architecture/) | Назначение портала, группы пользователей и способы доступа к порталу |
| [Функциональная архитектура](functional-architecture/) | Компоненты портала, их функции и сетевые взаимодействия |
| [Воркеры](workers/) | Настройка, мониторинг и масштабирование воркеров, которые выполняют фоновые задачи |

Требования к вычислительным ресурсам для разных профилей нагрузки приведены в разделе [«Требования к вычислительным ресурсам»](../resource-requirements/).
