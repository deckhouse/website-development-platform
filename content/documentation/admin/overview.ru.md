Руководство администратора Deckhouse Development Portal (DDP) описывает установку портала и настройку его механизмов: источников данных, действий, процессов, виджетов, проверок статуса и других.
Руководство входит в состав эксплуатационной документации продукта.

## Состав руководства

Руководство состоит из следующих разделов:

| Раздел | Содержание |
| --- | --- |
| [Установка](install/) | Установка портала с внутренними, внешними или managed-экземплярами PostgreSQL, Redis и ClickHouse |
| [Требования к вычислительным ресурсам](resource-requirements/) | Расчёт CPU, памяти и диска для разных профилей нагрузки |
| [Архитектура](architecture/overview/) | Компоненты портала, сетевые взаимодействия и воркеры |
| [Безопасность](security/overview/) | Ролевая модель, учётные данные, ключ шифрования, аудит-логи и HTTP-заголовки безопасности |
| [Главная страница](home/overview/) | Главная страница портала, правила маппинга и мастер первоначальной настройки |
| [Шаблоны микросервисов](templates/overview/) | Реестр шаблонов, пакеты шаблонов и обновление микросервисов из шаблона |
| [Действия](actions/overview/) | Настройка действий и справочник встроенных действий |
| [Процессы](processes/overview/) | Создание процессов, типы элементов, хранилище и управление выполнением |
| [AI-агенты](ai-agents/overview/) | Подключение AI-агентов, навыки и история запусков |
| [Источники данных](datasources/overview/) | Синхронизация сущностей из внешних систем и правила обработки данных |
| [Виджеты](widgets/overview/) | Виджеты для дашбордов и страниц сущностей |
| [Проверки статуса](healthchecks/overview/) | Правила, по которым определяется статус сущностей |
| [Автоматизации](automations/) | Автоматический запуск действий, процессов и синхронизации при изменении сущностей |
| [Вебхуки](webhooks/) | Приём данных из внешних систем по push-модели |
| [Внешние сервисы](external-services/) | Авторизация во внешних инфраструктурных сервисах |
| [Доверенные сертификаты](trusted-certificates/) | Сертификаты для HTTPS-соединений с внешними сервисами |
| [Наборы данных](datasets/) | Готовые конфигурации для интеграции с внешними системами |
| [Сценарии](workflows/) | Объединение действий в цепочку |
| [Рабочие пространства](workspaces/overview/) | Подготовка рабочих пространств, их шаблонов и источников |
| [Примеры настройки](examples/overview/) | Пошаговые сценарии настройки портала |

## Новые сценарии

Для настройки новых сценариев используйте руководства:

- [подготовка рабочих пространств](workspaces/overview/) — подключения, сеть, хранилище и лимиты;
- [создание шаблона](workspaces/templates/) — проект OpenTofu, параметры, публикация и активация;
- [файлы и скрипты](workspaces/files/) и [образы, Ingress и хранение](workspaces/network-storage/) — примеры изменения стартового шаблона;
- [AI-агенты](ai-agents/overview/) и [навыки](ai-agents/skills/) — инструменты и инструкции агентов.
