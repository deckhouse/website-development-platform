Виджет «AI-чат» отправляет вопросы [AI-агенту](../../ai-agents/overview/): задаются агент, общие инструкции («Глобальный промпт») и набор кнопок быстрых вопросов («Быстрые вопросы»).

## Конфигурация

| Название          | Обязательность | Описание                                                                                                                       |
| ----------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Агент             | Нет            | Агент, который отвечает в виджете. По умолчанию — платформенный агент. Задаётся только в настройках виджета, при работе с виджетом агента сменить нельзя |
| Глобальный промпт | Нет            | Общие инструкции к каждому запросу; при отправке объединяются с промптом выбранной кнопки быстрого вопроса                    |
| Быстрые вопросы   | Да             | Набор кнопок с подписью и текстом промпта (до 20); для корректной работы виджета добавьте хотя бы один вопрос                  |

Для каждого быстрого вопроса задайте следующие поля:

| Название         | Обязательность | Описание                                                                                    |
| ---------------- | -------------- | ------------------------------------------------------------------------------------------- |
| Название вопроса | Да             | Короткая подпись, отображаемая на нижней панели виджета и в чате                            |
| Промпт           | Да             | Инструкция для модели при нажатии на эту кнопку; допускается использование Go-шаблонизации |

При заполнении промпта явно укажите названия инструментов Model Context Protocol (MCP), которые должен вызвать агент при подготовке ответа. Агент вызывает только инструменты из списка «MCP-инструменты» своего подключения; платформенному агенту также доступны инструменты MCP-коллекций пользователя.

Инструмент `get_external_data` не входит в базовый набор платформенного агента. Чтобы использовать его в промпте, [добавьте инструмент](../../ai-agents/platform-agent/#добавление-инструментов) платформенному агенту.

Пример промпта для быстрого вопроса:

```text
1. Вызови MCP tool get_external_data для внешнего сервиса «Deckhouse Code» и получи пайплайны для проекта с ID {{ .entity.properties.deckhouse_code_id }}.
2. Выведи таблицу с последними 10 пайплайнами.
```

## Использование виджета

Для работы с виджетом требуется разрешение `run:ai-agents`. Если модель агенту предоставляет портал (платформенный агент или внешний агент с разрешённым прокси моделей DDP), у пользователя должен быть [AI-провайдер](../../../../user/ai-assistant/#подключение-ai-провайдера).

Для виджетов на странице сущности агент получает UUID сущности в контексте задачи.

У чата не предусмотрена история:

- Выводится только один ответ на последний заданный вопрос.
- Ответ не сохраняется при переходе на другую страницу или при обновлении страницы.

Перед отправкой вопроса измените промпт, выбрав пункт «Отправить с изменением промпта» в выпадающем меню кнопки вопроса.
