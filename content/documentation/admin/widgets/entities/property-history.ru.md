Виджет строит график изменений параметров сущности за выбранный период.
Период выбирается в заголовке виджета.

## Отображаемые данные

- «График» — числовые параметры отображаются линией значений, флаги — по оси со значениями «Нет» и «Да».
- «Точка на графике» — изменение параметра. В подсказке отображаются значение, источник изменения и автор.
- «Легенда» — отображается, если на графике больше одного параметра.
- «Граница хранения» — вертикальная отметка на графике, левее которой изменения уже удалены.

## Конфигурация

| Название              | Обязательность | Описание                                                                                                                                                  | Значение по умолчанию |
| --------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Ресурс                | Нет            | Ресурс, из схемы которого выбираются параметры. Если ресурс не указан, параметры задаются идентификаторами, а график строится по ресурсу текущей сущности | —                     |
| Параметры             | Да             | Параметры, изменения которых показывает график. Поддерживаются типы `Number`, `Percentage` и `Boolean`. Несколько параметров — только одного типа         | —                     |
| Интервал по умолчанию | Нет            | Период, за который виджет строит график при открытии                                                                                                      | Последние 30 дней     |
| Пороговое значение    | Нет            | Горизонтальная линия на графике, рисуется только для числовых параметров                                                                                  | —                     |
| Минимум оси           | Нет            | Нижняя граница оси значений                                                                                                                               | По данным             |
| Максимум оси          | Нет            | Верхняя граница оси значений                                                                                                                              | По данным             |

## Особенности

История изменений параметров ведётся только при подключённом ClickHouse. Если хранилище не настроено, виджет сообщает, что история параметров не ведётся.

Срок хранения истории ограничен. Если выбранный период целиком старше срока хранения, виджет сообщает, что изменения за него уже удалены.

Если за выбранный период изменений больше, чем помещается на график, виджет показывает предупреждение и называет параметры, часть изменений которых не показана. Уменьшите период или оставьте на графике меньше параметров.

Если в числовой параметр записано нечисловое значение, например текст, показать его на оси невозможно. В этом месте линия прерывается и продолжается со следующего числового значения, а само значение видно в подсказке.
