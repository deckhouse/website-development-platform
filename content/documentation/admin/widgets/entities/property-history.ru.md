Виджет строит график изменений свойств сущности за выбранный период.
Период выбирается в заголовке виджета.

## Отображаемые данные

- «График» — числовые свойства отображаются линией значений, флаги — по оси со значениями «Нет» и «Да».
- «Точка на графике» — изменение свойства. В подсказке отображаются значение, источник изменения и автор.
- «Легенда» — отображается, если на графике больше одного свойства.
- «Граница хранения» — вертикальная отметка на графике, левее которой изменения уже удалены.

## Конфигурация

| Название              | Обязательность | Описание                                                                                                                                                | Значение по умолчанию |
| --------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Ресурс                | нет            | Ресурс, из схемы которого выбираются свойства. Если ресурс не указан, свойства задаются идентификаторами, а график строится по ресурсу текущей сущности | —                     |
| Свойства              | **да**         | Свойства, изменения которых показывает график. Поддерживаются типы `Number`, `Percentage` и `Boolean`. Несколько свойств — только одного типа           | —                     |
| Интервал по умолчанию | нет            | Период, за который виджет строит график при открытии                                                                                                    | Последние 30 дней     |
| Пороговое значение    | нет            | Горизонтальная линия на графике, рисуется только для числовых свойств                                                                                   | —                     |
| Минимум оси           | нет            | Нижняя граница оси значений                                                                                                                             | По данным             |
| Максимум оси          | нет            | Верхняя граница оси значений                                                                                                                            | По данным             |

## Особенности

История изменений свойств ведётся только при подключённом ClickHouse. Если хранилище не настроено, виджет сообщает, что история свойств не ведётся.

Срок хранения истории ограничен. Если выбранный период целиком старше срока хранения, виджет сообщает, что изменения за него уже удалены.

Если за выбранный период изменений больше, чем помещается на график, виджет показывает предупреждение и называет свойства, часть изменений которых не показана. Уменьшите период или оставьте на графике меньше свойств.

Если в числовое свойство записано нечисловое значение, например текст, показать его на оси невозможно. В этом месте линия прерывается и продолжается со следующего числового значения, а само значение видно в подсказке.
