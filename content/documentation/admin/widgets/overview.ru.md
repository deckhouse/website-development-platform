Виджеты — карточки для визуализации данных, хранящихся в Deckhouse Development Portal (DDP), а также информации из инфраструктурных сервисов. В отличие от источников данных, виджеты получают информацию из инфраструктурных сервисов непосредственно в момент их отображения в интерфейсе.

Виджеты могут быть добавлены на дашборды. Дашборды, в свою очередь, могут быть привязаны:

- к статическим страницам («Каталог», «Самообслуживание», «AI», «Администрирование», «РБПО»);
- к карточкам сущностей.

Виджет также выводится на главной в [слоте виджета](../home/mapping/#слоты-виджетов) карточки микросервиса.

## Конфигурация

Конфигурация виджета включает общие параметры и набор полей, специфичных для конкретного типа виджета.

В конфигурации поддерживается использование синтаксиса [Go template](https://pkg.go.dev/text/template) для шаблонизации при обработке виджета, например:

* `{{ .entity.name }}` — подстановка значения параметра сущности `name`.
* `{{ .credentials.token }}` — подстановка учётных данных с названием `token`.
* `{{ .context.repository.id }}` — подстановка значения из контекста главной. Контекст передаётся только виджетам в слотах главной; состав контекста описан в разделе [«Слоты виджетов»](../home/mapping/#слоты-виджетов).

Для каждого виджета доступно задание области видимости:

* `Global` — виджет не поддерживает получение параметров сущности через механизм Go template;
* `Resource` — виджет поддерживает получение параметров сущности через механизм Go template. Виджеты с областью видимости `Resource` можно прикрепить только к страницам сущности.

В конфигурации виджетов возможно задание учётной записи, с данными которой виджет будет взаимодействовать с инфраструктурными системами, а также выбрать тип учётных данных, который будет использоваться.

Если учётная запись не задана, виджет будет использовать учётные данные пользователя, взаимодействующего с порталом в текущий момент.
