The widget displays a table of product dependencies based on CodeScoring data.
For each dependency, the table includes its name, version, license, number of vulnerabilities, and other information.

## Configuration

When adding the widget, specify the following parameters:

| Name       | Required | Description                | Default value |
| ---------- | -------- | -------------------------- | ------------- |
| URL        | Yes      | CodeScoring URL            | —             |
| Project ID | Yes      | Project ID in CodeScoring  | —             |
