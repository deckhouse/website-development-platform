The widget displays text written in Markdown.

## Configuration

When adding the widget, specify the following parameters:

| Name     | Required | Description                                       | Default value |
| -------- | -------- | ------------------------------------------------- | ------- |
| Markdown | Yes      | Markdown text rendered in the widget              | —       |
