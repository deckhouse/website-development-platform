Виджет индекса OpenSearch позволяет отображать данные из заданного индекса или шаблона индекса. По умолчанию данные сортируются от новых к старым. Для фильтрации доступен полнотекстовый поиск. Каждую запись в таблице можно просмотреть в формате «ключ — значение» или JSON. Если указан шаблон индекса, виджет отображает ссылку на страницу Discover в OpenSearch Dashboards.

## Авторизация

Конфигурация авторизации описана в разделе [«Внешние сервисы»](../../external-services/#opensearch).

## Конфигурация

| Название             | Обязательность | Описание                                                                                                                       | Значение по умолчанию |
| -------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------ | --------------------- |
| URL API              | Да             | URL API OpenSearch для получения данных                                                                                         | —                     |
| URL Dashboards       | Да             | URL OpenSearch Dashboards для создания ссылки на данные в OpenSearch                                                           | —                     |
| Шаблон индекса       | Да             | Шаблон индекса, из которого виджет загружает данные. Может содержать `*`. Примеры: `security-auditlog`, `security-auditlog-*` | —                     |
| Поле временной метки | Нет            | Название поля с временной меткой. Значение отображается в отдельном столбце таблицы                                             | `@timestamp`          |
