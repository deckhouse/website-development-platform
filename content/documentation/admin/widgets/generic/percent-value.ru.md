Виджет позволяет отображать заданное процентное значение.

## Конфигурация

| Название            | Обязательность | Описание                                                                                                                                                         | Значение по умолчанию |
| ------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Процент             | Нет            | Значение, которое будет выводиться на виджет. Шаблонизация поддерживается. Пример без шаблонизации: `100`. Пример с шаблонизацией: `{{ .entity.properties.id }}` | —                     |
