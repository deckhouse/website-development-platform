Виджет отображает структуру задач в пространстве Kaiten
в виде многоуровневой таблицы «Доска → Карточки».
Используйте его, чтобы просматривать задачи на всех уровнях организации работы
и ключевые сведения о карточках: статус, срочность, состояние блокировки и исполнителей.

## Конфигурация

| Название        | Обязательность | Описание                            | Значение по умолчанию |
| --------------- | -------------- | ----------------------------------- | --------------------- |
| Идентификатор пространства | Да             | Идентификатор пространства в Kaiten | —                     |

## Параметры запроса

| Название      | Обязательность | Описание                        | Значение по умолчанию |
| ------------- | -------------- | ------------------------------- | --------------------- |
| Мои задачи    | Нет            | Фильтр по текущему пользователю | `false`               |
| Создано после | Да             | Начальная дата для выборки      | 1 месяц назад         |
| Создано до    | Да             | Конечная дата для выборки       | Сейчас                |

## Авторизация

Конфигурация авторизации описана в разделе [«Внешние сервисы»](../../external-services/#kaiten).

## Отображаемые данные

Каждая карточка содержит:

- Название карточки.
- Колонка (статус в доске).
- Статус (очередь, в работе, готово).
- Линия.
- Владелец (аватар, имя, email).
- Участники.
- Срок выполнения и срочность.
- Состояние блокировки.
