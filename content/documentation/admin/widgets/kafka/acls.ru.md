Виджет отображает список правил контроля доступа (ACL) кластера Kafka.

Для каждого ACL отображается следующая информация:

* Субъект.
* Тип ресурса.
* Шаблон.
* Тип шаблона.
* Хост.
* Операция.
* Тип разрешения.

## Дополнительные возможности виджета

Если включён параметр «Включить действия виджета», виджет позволяет создавать и удалять правила ACL.

## Аутентификация

Виджет подключается к Kafka с учётной записью, указанной в полях «Пользователь Kafka» и «Пароль». Эти поля нужны для протоколов `SASL_PLAINTEXT` и `SASL_SSL`.

Поддерживаются протоколы аутентификации:

* `PLAINTEXT`;
* `SASL_PLAINTEXT`;
* `SASL_SSL`.

Для протоколов `SASL_PLAINTEXT` и `SASL_SSL` поддерживаются механизмы SASL:

* `PLAIN`;
* `SCRAM-SHA-256`;
* `SCRAM-SHA-512`.
