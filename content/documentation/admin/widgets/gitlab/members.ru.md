Виджет показывает графики активности коммитов в ветке или теге проекта GitLab за выбранный период.

## Конфигурация

При добавлении виджета задайте следующие параметры:

| Название   | Обязательность | Описание                                                                   | Значение по умолчанию |
| ---------- | -------------- | -------------------------------------------------------------------------- | --------------------- |
| URL        | Да             | URL GitLab API. Используется для получения данных из GitLab                | —                     |
| ID проекта | Да             | ID проекта, из которого будут загружаться данные в виджет. Пример: `12345` | —                     |

## Параметры запроса

В параметрах запроса виджета задаются ветка или тег и период:

| Название | Обязательность | Описание                                       | Значение по умолчанию         |
| -------- | -------------- | ---------------------------------------------- | ----------------------------- |
| Ref      | Нет            | Ветка или тег, коммиты которых анализирует виджет | Ветка проекта по умолчанию |
| от       | Нет            | Начальная дата периода                         | Дата на год раньше текущей    |
| до       | Нет            | Конечная дата периода                          | Текущая дата                  |

## Отображаемые данные

Виджет показывает графики с количеством коммитов по месяцам: общее количество коммитов в выбранной ветке или теге
и отдельный график для каждого из 12 авторов с наибольшим количеством коммитов с именем автора, email и количеством коммитов за период.

В заголовке виджета отображаются выбранный период и ветка или тег.

## Ограничения

Графики строятся по 1000 последних коммитов за период.
В виджете отображается примечание «Отображается 1000 последних коммитов».
Период ограничен 730 днями. Если выбранный период длиннее, виджет сокращает его до 730 дней перед конечной датой.
