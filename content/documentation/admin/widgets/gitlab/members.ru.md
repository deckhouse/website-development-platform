Виджет позволяет отображать данные об участниках проекта в GitLab. More information about members is available in the [GitLab documentation](https://docs.gitlab.com/user/project/members/).

## Конфигурация

| Название   | Обязательность | Описание                                                                   | Значение по умолчанию |
| ---------- | -------------- | -------------------------------------------------------------------------- | --------------------- |
| ID проекта | Да             | ID проекта, из которого будут загружаться данные в виджет. Пример: `12345` | —                     |
