## GitLab. Участники

Виджет позволяет отображать данные об участниках проекта в GitLab. [Подробнее об участниках](https://docs.gitlab.com/user/project/members/).

### Авторизация

Конфигурация авторизации описана в разделе [«Внешние сервисы»](../../external-services/#gitlab).

### Конфигурация

| Название   | Обязательность  | Описание                                                                   | Значение по умолчанию |
|------------|-----------------|----------------------------------------------------------------------------|-----------------------|
| ID проекта | Да | ID проекта, из которого будут загружаться данные в виджет. Пример: `12345` | -                     |
