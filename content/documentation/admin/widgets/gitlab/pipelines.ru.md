Виджет показывает пайплайны проекта GitLab, их этапы и задачи и позволяет запускать, перезапускать и останавливать пайплайны и задачи из Deckhouse Development Portal (DDP).

## Конфигурация

| Название   | Обязательность | Описание                                                                   | Значение по умолчанию |
| ---------- | -------------- | -------------------------------------------------------------------------- | --------------------- |
| URL        | Да             | URL GitLab API. Используется для получения данных из GitLab                | —                     |
| ID проекта | Да             | ID проекта, из которого будут загружаться данные в виджет. Пример: `12345` | —                     |

## Таблица пайплайнов

В таблице отображаются колонки:

- ID — номер пайплайна со ссылкой на GitLab;
- «Статус» — состояние пайплайна;
- Ref — ветка или тег;
- «Источник» — событие, которое запустило пайплайн;
- «Инициатор» — пользователь, запустивший пайплайн;
- «Длительность» и «Завершено»;
- меню «Действия».

В меню «Действия» доступны:

- «Перезапустить пайплайн»;
- «Остановить пайплайн» — для ожидающих и выполняющихся пайплайнов;
- «Открыть в GitLab».

## Этапы и задачи

Нажмите на строку пайплайна, чтобы раскрыть время создания, запуска и завершения и этапы пайплайна. Для каждого этапа отображаются статус, число задач с ошибкой и задачи этапа. Если задач больше восьми, остальные скрыты под кнопкой «Показать ещё {count}».

Нажмите на задачу, чтобы открыть панель задачи. В панели отображаются название, номер задачи со ссылкой на GitLab, этап, длительность и кнопки:

- «Запустить задачу» — для задач с ручным запуском;
- «Перезапустить задачу» — недоступна для задач с ручным запуском и ожидающих задач;
- «Остановить задачу» — для ожидающих, запланированных и выполняющихся задач.

### Журнал задачи

В панели задачи отображается журнал выполнения: по умолчанию последние 50 строк. Кнопка «Полный лог» показывает журнал целиком, кнопка «Последние строки» возвращает сокращённый вид. Цвета вывода задачи сохраняются.

Если задача ещё не запускалась, отображается сообщение «Задача ещё не запускалась — лога нет».

## Запуск пайплайна

Кнопка «Запустить пайплайн» в заголовке виджета запускает пайплайн в GitLab.

Параметры запуска:

| Название   | Обязательность | Описание                                                                          | Значение по умолчанию |
| ---------- | -------------- | --------------------------------------------------------------------------------- | --------------------- |
| Ref        | Да             | Целевая ветка или тег для запуска пайплайна                                       | —                     |
| Переменные | Нет            | Переменные в формате ключ-значение, которые будут переданы в запускаемый пайплайн | —                     |

## Размещение на главной

Виджет выводится на вкладке «Пайплайны» карточки микросервиса на главной, если он выбран в слоте `microservice_repository_widget` [правил маппинга](../../home/mapping/#слоты-виджетов).
В этом случае в поле «ID проекта» укажите `{{ .context.repository.id }}`: карточка микросервиса передаёт виджету ID проекта своего репозитория.
