Виджет позволяет отображать данные о пайплайнах в GitLab.

## Конфигурация

| Название   | Обязательность | Описание                                                                   | Значение по умолчанию |
| ---------- | -------------- | -------------------------------------------------------------------------- | --------------------- |
| URL        | Да             | URL GitLab API. Используется для получения данных из GitLab                | —                     |
| ID проекта | Да             | ID проекта, из которого будут загружаться данные в виджет. Пример: `12345` | —                     |

## Дополнительные возможности виджета

### Запуск пайплайнов

Виджет позволяет запускать пайплайны в GitLab напрямую из Deckhouse Development Platform (DDP).

#### Конфигурация

| Название   | Обязательность | Описание                                                                          | Значение по умолчанию |
| ---------- | -------------- | --------------------------------------------------------------------------------- | --------------------- |
| Ref        | Да             | Целевая ветка или тег для запуска пайплайна                                       | —                     |
| Переменные | Нет            | Переменные в формате ключ-значение, которые будут переданы в запускаемый пайплайн | —                     |

### Управление пайплайнами и задачами

Строку пайплайна можно развернуть и увидеть его стадии и задачи. Для пайплайна и для отдельной задачи доступны действия:

- «Перезапустить пайплайн» и «Остановить пайплайн»;
- «Запустить задачу», «Перезапустить задачу» и «Остановить задачу».

Набор доступных действий зависит от текущего состояния: остановить можно только выполняющийся объект, перезапустить — уже завершившийся.

### Журналы задач

Для задачи виджет показывает журнал выполнения: последние строки прямо в строке задачи и полный журнал в отдельной панели. Управляющие последовательности ANSI отображаются с сохранением цвета. Если задача ещё не запускалась, виджет сообщает об этом вместо пустого журнала.
