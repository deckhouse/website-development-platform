Каждое обращение к AI-агенту создаёт запуск: ответ на вопрос в AI-ассистенте, ответ виджета «AI-чат», выполнение элемента процесса «AI-агент».
Запуск хранит сообщение агенту, ответ, вызовы инструментов, ошибку и результат.

## История запусков

История открывается в разделе «AI» → «AI-агенты» → «История запусков» и доступна с разрешением `read:ai-agent-runs`.
Пользователь видит только свои запуски, супер-администратор — запуски всех пользователей.

Таблицу запусков можно отфильтровать по полям:

| Фильтр | Описание |
| --- | --- |
| «Статус» | Статус запуска |
| «Триггер» | Откуда запущен агент |
| «Агент» | Идентификатор агента |
| «Начало периода», «Конец периода» | Интервал времени начала запуска. Начало периода должно быть не позже конца |
| «Поиск по агенту, провайдеру или ошибке» | Подстрока длиной до 64 символов в идентификаторе или названии агента, названии AI-провайдера или тексте ошибки |

## Статусы запуска

Запуск находится в одном из статусов:

| Статус | Значение |
| --- | --- |
| «Выполняется» (`running`) | Агент выполняет задачу |
| «Успешно» (`succeeded`) | Агент вернул ответ |
| «Ошибка» (`failed`) | Запуск завершился ошибкой, превысил максимальную длительность или был прерван |
| «Отменён» (`cancelled`) | Запуск остановлен пользователем или вместе с процессом |

## Триггеры

Поле «Триггер» показывает, откуда запущен агент:

| Триггер | Откуда запускается агент |
| --- | --- |
| «Чат» | Вопрос в AI-ассистенте |
| «Виджет» | Вопрос в виджете «AI-чат» |
| «Процесс» | Элемент «AI-агент» в запуске процесса |

## Детали запуска

Чтобы открыть детали, нажмите «Открыть» в строке запуска. В окне «Детали запуска агента» отображаются агент, статус, триггер, AI-провайдер, время начала и окончания, ошибка и ответ провайдера, а также результат запуска.

Тип результата отображается в поле «Тип deliverable»:

| Тип | Когда используется | Ссылка |
| --- | --- | --- |
| «Сообщение» | Агент вернул текстовый ответ | UUID запуска |
| «Store процесса» | Агент выполнен элементом процесса, результат записан в хранилище процесса | Ключ хранилища |
| «Merge request», «Ветка», «Patch» | Внешний агент сообщил о результате в метаданных ответа | Ссылка на merge request, ветку или patch |

Как внешний агент сообщает тип результата — в разделе [«Результат запуска»](external-agents/#результат-запуска).

## Остановка запуска

Чтобы остановить запуск в статусе «Выполняется», нажмите «Остановить» в строке запуска или в окне деталей и подтвердите действие. Кнопка доступна с разрешением `cancel:ai-agent-runs`.

После остановки:

- запуск получает статус «Отменён»;
- портал отзывает токен запуска, и агент больше не может вызывать инструменты портала и обращаться к модели через портал;
- если агент запущен элементом процесса, процесс продолжает работу по правилам обработки ошибок элемента.

Портал не отправляет внешнему агенту команду отмены задачи. Агент продолжает работу до следующего обращения к порталу, которое завершается ошибкой `401`.

Запуски, созданные элементами процесса, также останавливаются при остановке и принудительном перезапуске процесса.
