Статистика показывает использование AI-агентов, моделей, MCP-инструментов, навыков и рабочих пространств. Данные собираются по дням UTC и обновляются раз в час; время последнего успешного обновления указано в «Данные на».

## Личная статистика

В AI-ассистенте нажмите «Моя статистика». Диалог показывает только ваши данные и доступен пользователю, которому разрешено пользоваться чатом.

Выберите период и вкладку с нужными показателями:

| Вкладка | Что показывает |
| --- | --- |
| «Обзор» | Запуски агентов, вызовы MCP, токены, задания рабочих пространств и активность |
| «Агенты» | Запуски по агентам и типам запуска, результаты и длительность |
| «Модели» | Запросы и входные/выходные токены по моделям и контексту использования |
| «MCP» | Вызовы инструментов и серверов, ошибки и длительность |
| «Рабочие пространства» | Операции, задания, токены, ожидание подтверждений и изменения файлов |
| «Навыки» | Назначение навыков и фактическое чтение агентами |

Для сравнения доступны периоды «7 дней», «30 дней», «90 дней» и «365 дней». Учитывайте, что недавно выполненная работа появится после следующего обновления агрегатов.

## Статистика установки

Общая статистика открывается в «AI» → «Использование» → «Статистика» с разрешением `read:ai-statistics`. Она включает дополнительную вкладку «Пользователи» и выбор собственного периода.

Чтобы найти источник расхода:

1. Выберите период.
1. На вкладке «Модели» сравните входные и выходные токены.
1. На вкладке «Пользователи» выберите пользователя, чтобы отфильтровать остальные вкладки по нему.
1. Проверьте «Агенты», «Рабочие пространства» и «MCP» для определения вида работы.

## Значение показателей

При интерпретации учитывайте способ подсчёта:

| Показатель | Значение |
| --- | --- |
| Токены моделей | Учитываются по отчётам использования, полученным от провайдера. «С отчётом об использовании» показывает число запросов с таким отчётом |
| p50 и p95 | Приближённые значения длительности по группам измерений; незавершённые операции в них не входят |
| Навык «Подключён» | Был назначен агенту или рабочему пространству; это не означает, что агент его прочитал |
| Навык «Использован» | Агент прочитал навык через `get_skill` либо инструмент навыков рабочего пространства |
| Навык «нет в каталоге» | Навык удалён или прочитан не из каталога DDP |
| Рабочие пространства у навыка | Сумма по дням пространств с заданиями; одно пространство может учитываться в разные дни |
| «По TTL» | Остановка рабочего пространства по истечении срока работы |

Статистика использования не заменяет расчёт стоимости у провайдера. Если провайдер не возвращает отчёт о токенах, число запросов и число запросов с отчётом могут различаться.

## Хранение данных

При установке модулем срок хранения суточных агрегатов задаётся в ModuleConfig, в `spec.settings.ai.statistics.retentionDays`. По умолчанию — 365 дней. Пример изменения срока:

```yaml
ai:
  statistics:
    retentionDays: 180
```

Агрегаты старше срока удаляются раз в час. Срок хранения подробных журналов запусков и MCP-вызовов задаётся отдельно; сохранённая статистика может оставаться после удаления подробных записей.
