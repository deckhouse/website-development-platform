Deckhouse Development Portal (DDP) объединяет каталог сервисов, действия, процессы и инструменты AI. Начните со сценария, который нужен для работы:

| Задача | Руководство |
| --- | --- |
| Найти сервис и его связи | [Каталог](catalog/) |
| Запустить действие или процесс | [Страница сущности](catalog/#страница-сущности) |
| Подключить языковую модель | [AI-провайдер в профиле](ai-assistant/#подключение-ai-провайдера) |
| Создать IDE с агентом для проекта | [Создание рабочего пространства](workspaces/#создание-рабочего-пространства) |
| Поручить агенту изменить файлы | [Чат рабочего пространства](workspace-chat/) |
| Подключить MCP-клиент | [MCP-сервер](mcp-server/#подключение-mcp-сервера) |
| Посмотреть использование AI | [Статистика AI](ai-statistics/) |

Набор доступных действий определяется ролями и доступом к конкретным объектам. Для рабочих пространств администратор предварительно подготавливает шаблоны и лимиты.
