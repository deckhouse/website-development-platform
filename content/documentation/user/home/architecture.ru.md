Разделы группы «Архитектура» показывают системы, связи между ними и инфраструктуру, на которой они размещены. Разделы группы предназначены для просмотра и не запускают процессы.

## Системы

Раздел «Системы» показывает системы, сгруппированные по доменам, и сведения о выбранной системе.

### Дерево доменов

В левой панели «Домены» системы сгруппированы по доменам. Домены и системы отсортированы по названию.
Поле «Поиск по системе или домену» фильтрует дерево по названию домена или системы.

Системы без домена в дереве не отображаются.

При открытии раздела выбрана первая по названию система. Чтобы выбрать другую систему, нажмите на неё в дереве.

### Вкладки системы

Сведения о выбранной системе распределены по вкладкам. При выборе системы открывается вкладка «Зависимости».

| Вкладка | Содержимое |
| --- | --- |
| «Справка» | «Домен», «Владелец», «Команда владелец», «Жизненный цикл», «Состояние» |
| «Зависимости» | Граф зависимостей системы и таблица интеграций с колонками «Клиент», «Сервер», «Интеграция» |
| «Микросервисы» | Микросервисы системы: «Микросервис», «Язык», «Состояние» |
| «Общесистемные ресурсы» | Общие ресурсы системы: «Ресурс», «Тип» |
| «Окружения» | Окружения, на которых развёрнуты микросервисы системы: «Название», «Тип», «Кластер» |

Поле «Состояние» показывает результат проверок статуса сущности: «В норме», «С проблемами», «Ошибка» или «Неизвестно».

### Граф зависимостей

Граф зависимостей показывает выбранную систему и системы, с которыми она связана интеграциями. Системы связаны друг с другом только через интеграции: система-клиент обращается к системе-серверу через интеграцию.

На линии между двумя системами отображаются названия интеграций. Если интеграций больше одной, остальные скрыты под тегом «+N»; наведите на тег, чтобы увидеть их список. Если системы обращаются друг к другу в обе стороны, линия отмечена стрелками с обоих концов.

Нажмите на линию или название интеграции, чтобы открыть панель интеграции. В панели отображаются описание интеграции, системы «Клиент» и «Сервер», «Тип связи» и «Критичность».

Если у системы нет интеграций, отображается сообщение «У выбранной системы нет зависимостей.».

## Интеграции

Раздел «Интеграции» показывает все интеграции между системами.

В верхней части раздела отображаются показатели:

- «Интеграции» — число интеграций;
- «Зависимости» — число пар систем «клиент — сервер», связанных интеграциями;
- «Критичные связи» — число интеграций с высокой критичностью.

На вкладке «Таблица» интеграции перечислены с колонками «Интеграция», «Клиент», «Сервер», «Тип связи», «Критичность». Нажмите на строку, чтобы открыть панель интеграции.

На вкладке «Граф» отображается граф зависимостей первой системы каталога.

## Диаграммы

Раздел «Диаграммы» показывает схемы системы в трёх видах. Вид выбирается переключателем:

- «Зависимости» — граф зависимостей системы через интеграции;
- «Состав» — дерево системы с её микросервисами и общими ресурсами;
- «Развёртывание» — сводка по системе, её микросервисам и общим ресурсам. Систему выберите в списке «Система».

Кнопка «Скачать диаграмму» сохраняет выбранную схему в текстовый файл.

## Кластеры и сети

Раздел «Кластеры и сети» показывает кластеры и окружения, размещённые в них.

В верхней части раздела отображаются показатели «Кластеры» и «Окружения». Для каждого кластера отображается карточка с провайдером, названием, регионом и окружениями кластера.

## Как работает платформа

Раздел «Как работает платформа» содержит гайды по основным сценариям работы с порталом. Гайды сгруппированы по категориям; гайды без категории отображаются в группе «Без категории».

Гайды фильтруются полем «Поиск по гайдам» и переключателем категорий. Переключатель категорий отображается, если категорий больше одной.

В карточке гайда отображаются категория, дата обновления, название и описание. Кнопка «Открыть документацию» открывает документацию гайда, кнопка «Смотреть видео» — видео.
