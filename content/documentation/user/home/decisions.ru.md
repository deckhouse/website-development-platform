Раздел «Главная» → «AI-инструменты» → «Решения» показывает решения процессов, адресованные вам. Здесь можно согласовать спецификацию [изменения приложения](applications/) или ответить на вопрос другого процесса.

## Ответ на вопрос

Чтобы продолжить ожидающий процесс:

1. Откройте вкладку «Ожидают».
1. Найдите вопрос по объекту, процессу и шагу. При необходимости откройте объект: для AI PDLC ссылка ведёт на изменение, для остальных процессов — на сущность каталога.
1. Прочитайте вопрос, укажите необязательный «Комментарий» и выберите один из предложенных ответов.

Если адресатов несколько, отвечает любой из них. Первый принятый ответ завершает ожидание; изменить его повторным нажатием нельзя. Если другой адресат уже ответил, портал сообщает «Решение уже принято».

Отвечать могут адресаты и суперадминистратор. Разрешение управлять процессом само по себе не делает пользователя адресатом решения. Если все адресаты удалены, ответить может только суперадминистратор.

## Принятые решения

Вкладка «Принятые» показывает ранее адресованные вам решения с выбранным ответом, автором и временем ответа. Для проверки контекста откройте связанное изменение или сущность.

Как добавить вопрос и варианты ответа в схему процесса, описано в руководстве [«Решение в процессе»](../../admin/processes/decisions/).
