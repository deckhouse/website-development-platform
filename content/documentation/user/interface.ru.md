Интерфейс Deckhouse Development Portal (DDP, портал) объединяет разделы для работы с проектами:

- «Главная» — страница разработчика: рабочие пространства с AI-агентом и IDE, команды, системы, микросервисы, окружения, развёртывание и заказ ресурсов. Подробнее — в разделе [«Главная»](home/overview/).
- «Каталог» — сервисный каталог для просмотра ресурсов, сущностей и связей, а также для запуска действий и сценариев.

## Верхняя панель

В правой части верхней панели портала расположены кнопки:

- «AI-ассистент» — открывает окно [AI-ассистента](ai-assistant/#работа-с-ai-ассистентом). На странице рабочего пространства чат встроен в страницу, поэтому кнопка недоступна;
- «Мои активности» — открывает панель с запусками ваших действий и процессов. Пока у вас выполняются процессы, значок кнопки заменяется индикатором, а на вкладке «Процессы» отображается число выполняющихся процессов.

## Глобальный поиск

В верхней части боковой панели раздела «Каталог» доступно поле «Поиск». Оно позволяет быстро находить сущности по всему порталу.

### Ограничения

- Максимальная длина запроса: 255 символов.
- Поиск работает только по сущностям. Ресурсы, команды и другие объекты портала в результаты не попадают.
