Интерфейс Deckhouse Development Portal (DDP, портал) состоит из следующих разделов:

- «Главная» — страница разработчика: команды, системы, микросервисы, окружения, развёртывание и заказ ресурсов. Вкладка отображается, если главная включена администратором. Подробнее — в разделе [«Главная»](home/overview/).
- «Каталог» — сервисный каталог для просмотра ресурсов, сущностей и связей, а также для запуска действий и сценариев.
- «Самообслуживание» — раздел для настройки источников данных, действий, вебхуков, автоматизаций, сценариев, дашбордов и виджетов. Доступ к разделу может быть ограничен ролевой моделью.
- «AI» — раздел рабочих пространств, навыков, агентов, AI-провайдеров, MCP-инструментов и статистики использования. Подробнее — в разделе [«Управление MCP»](mcp-management/). Доступ к разделу может быть ограничен ролевой моделью.
- «Администрирование» — раздел для управления командами, пользователями, политиками доступа и учётными данными. Доступ к разделу может быть ограничен ролевой моделью.

## Раздел AI

Раздел «AI» открывается на каталоге агентов. Настройки и журналы сгруппированы в боковом меню:

| Группа | Пункты меню |
| --- | --- |
| «Агенты» | «Каталог», «Источники агентов», «Шаблоны провайдеров» |
| «MCP» | «Каталог», «MCP-серверы», «MCP-коллекции», «MCP-инструменты» |
| «Рабочие пространства» | «Рабочие пространства», «Шаблоны рабочих пространств», «Источники шаблонов» |
| «Навыки» | «Навыки», «Источники навыков» |
| «Использование» | «Аудит», «Статистика» |

Каталог агентов показывает источник языковой модели: «Модель DDP» означает работу через AI-провайдера запускающего пользователя, «Модель агента» — собственное подключение внешнего агента к модели. Платформенный агент всегда использует модель DDP.

## Верхняя панель

В правой части верхней панели портала расположены кнопки:

- «AI-ассистент» — открывает окно [AI-ассистента](ai-assistant/#работа-с-ai-ассистентом);
- «Мои активности» — открывает панель с запусками ваших действий и процессов. Пока у вас выполняются процессы, значок кнопки заменяется индикатором, а на вкладке «Процессы» отображается число выполняющихся процессов.

## Глобальный поиск

В верхней части боковой панели раздела «Каталог» доступно поле «Поиск». Оно позволяет быстро находить сущности по всему порталу.

### Ограничения

- Максимальная длина запроса: 255 символов.
- Поиск работает только по сущностям. Ресурсы, команды и другие объекты портала в результаты не попадают.
