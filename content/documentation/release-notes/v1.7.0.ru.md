## Новые возможности

### Реестр шаблонов

- Добавлен [«Реестр шаблонов»](../../admin/template-registry/): синхронизация OCI-шаблонов, создание собственных шаблонов, обновление сервисов до новой версии (вручную и «Ревью автоматически»), галерея на главной. При создании микросервиса параметры из `values.yaml` и реквизиты сервиса задаются в одном окне.
- Добавлен набор данных [«Реестр шаблонов микросервисов»](../../admin/datasets/#реестр-шаблонов-микросервисов) с процессами создания и обновления микросервисов из шаблонов. Создание запускается из галереи: реквизиты сервиса и values шаблона — через context, в форме процесса — параметры VCS (например «Группа GitLab»).
- Добавлены разрешения `read:template-registry`, `update:template-registry` и `sync:template-registry`. Подробнее — в разделе [«Ролевая модель»](../../admin/security/rbac/).
